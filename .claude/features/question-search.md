## Проблема / цель
На доске 60+ карточек; найти нужный вопрос глазами/панорамированием медленно. Нужна строка поиска,
которая фильтрует доску по тексту (заголовок/вопрос/тема/теги): нерелевантные карточки гаснут.

## Поведение / UX
- В панели фильтров (top-right) сверху — поле «Поиск по вопросам…». Ввод гасит карточки, не совпавшие
  по подстроке (регистронезависимо) в `title` / `question` / `topic` / `tags`.
- Пусто → поиск не влияет (как тег-фильтр при отсутствии активных тегов).
- Совмещается с прочими фильтрами (блок/сложность/тип/теги) — всё через единый `dimmed`.

## Затрагиваемые слои и файлы
- backend: нет.
- frontend: `App.tsx` (state `query`, `matchesQuery`, проброс в `buildNodes` → `dimmed`, поле ввода в
  filterpanel), `styles.css` (`.fp__search`).
- content: нет. tests: smoke — ввод запроса гасит часть нод; очистка убирает гашение.

## Модель данных
Без изменений (UI-стейт).

## Решения (с обоснованием)
- **Через существующий `dimmed`** — консистентно с блок/сложность/тип/тег-фильтрами; ноль новой механики.
- Поиск по подстроке (не fuzzy) — просто и предсказуемо для интервью.
