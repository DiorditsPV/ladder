## Проблема / цель
По ходу интервью удобно быстро спрятать уже оценённые вопросы и видеть только оставшиеся. Сейчас такого
переключателя нет. («Только задачи» уже доступно через фильтр Тип — здесь не дублируем.)

## Поведение / UX
- В панели фильтров — переключатель «Только неоценённые». Включён → оценённые карточки гаснут
  (через тот же `dimmed`). Выключен → не влияет.
- Совмещается с прочими фильтрами (блок/сложность/тип/теги).

## Затрагиваемые слои и файлы
- backend: нет.
- frontend: `App.tsx` (state `unscoredOnly`, параметр в `buildNodes` → `dimmed`, чип-тумблер в filterpanel),
  `styles.css` (переиспользуем `.fp__chip`). tests: smoke — оценить ноду, включить тумблер, она гаснет.

## Модель данных
Без изменений (UI-стейт).

## Решения (с обоснованием)

- Реализуем только «неоценённые» (задачи уже есть в фильтре Тип) — не плодим дубль.
