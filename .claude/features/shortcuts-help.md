## Проблема / цель
В приложении есть клавиатурная навигация (1–5, Enter, n, Esc, стрелки), но узнать о ней неоткуда — она
скрыта. Нужен оверлей-шпаргалка со списком всех горячих клавиш, открываемый по «?» (и кнопкой в шапке для
мыши). Снижает порог входа для ведущего интервью.

## Поведение / UX
- Нажатие «?» (Shift+/) открывает модалку-оверлей `.help-modal` со списком хоткеев. Кнопка `?` (`.helpbtn`)
  в шапке — то же самое для мыши.
- Содержимое — реальные клавиши из обработчика `App.tsx` (НЕ выдуманные):
  - `1`–`5` — оценить текущий вопрос;
  - `Enter` — открыть карточку текущего вопроса (drawer);
  - `n` — перейти к следующему неоценённому;
  - `↑ ↓ ← →` — навигация по сетке (между вопросами/колонками);
  - `Esc` — снять выделение текущего (при закрытой карточке) / закрыть эту шпаргалку.
- Закрытие: «?» (тоггл), `Esc`, клик по фону, кнопка ✕.
- Пока оверлей открыт, прочие хоткеи (оценка/навигация) НЕ срабатывают — клавиатура «захвачена» шпаргалкой
  (иначе «5» под открытой подсказкой случайно поставит оценку).

## Затрагиваемые слои и файлы
- backend: нет.
- frontend: `App.tsx` (state `helpOpen`, обработка «?» + guard в существующем `onKey`, кнопка `.helpbtn`,
  рендер оверлея), `components/ShortcutsHelp.tsx` (новый, презентационный), `styles.css`
  (`.help-modal*`, `kbd`).
- content: нет.
- tests: `frontend/smoke.mjs` — нажать «?» → `.help-modal` виден и содержит известную подпись; `Esc` закрывает.

## Модель данных
Без изменений (UI-стейт).

## Решения (с обоснованием)
- **Захват клавиатуры через guard в начале `onKey`**: `if (helpOpen) { if (e.key === "Escape" || e.key === "?")
  setHelpOpen(false); return; }`. Так Esc/«?» закрывают оверлей, а остальные клавиши при открытом оверлее
  игнорируются — без отдельного слушателя в компоненте (один источник правды по клавиатуре = `App.tsx`).
- **Открытие «?»** добавляем в тот же `onKey` (после guard, до стрелок): `if (e.key === "?") { setHelpOpen(true);
  return; }`. `helpOpen` — в deps эффекта.
- **Презентационный компонент `ShortcutsHelp`** (только разметка + onClose), без своей клавиатурной логики —
  чтобы не плодить конкурирующие слушатели Esc (как договорились — клавиши держит App).
- **Кнопка `?` в шапке** — для мыши/обнаружимости; reuse `.iconbtn`.
- Список хоткеев — статический массив пар [клавиша, описание], сверен с реальным обработчиком.
