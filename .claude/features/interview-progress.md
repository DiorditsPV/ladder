## Проблема / цель
Ведущему интервью не видно «сколько ещё осталось»: счётчик `оценено N` есть только при активной сессии и
не показывает знаменатель/долю. Нужен компактный прогресс-бар «пройдено/осталось» в шапке — мгновенный
ответ на «далеко ли до конца» по текущему набору вопросов.

## Поведение / UX
- В шапке (`topbar`), рядом со счётчиком «{N} нод», — тонкий прогресс-бар + подпись `оценено D / T (P%)`.
- **Область прогресса = текущий отфильтрованный набор** (ноды, проходящие фильтры блок/сложность/тип/теги —
  тот же предикат, что даёт `dimmed=false`). Так бар отражает «выбранную область»: включил фильтр на один
  блок → бар считает только его. (Профиль/треки живут на отдельной ветке и в main недоступны — фильтры
  это ближайший и всегда доступный аналог.)
- Заполнение бара = `D/T`. При `T=0` (всё отфильтровано) — бар пустой, подпись `оценено 0 / 0`.
- Обновляется реактивно при оценке вопроса и смене фильтров. Видно всегда (и без активной сессии).

## Затрагиваемые слои и файлы
- backend: нет.
- frontend: `App.tsx` (memo `coverage` над отфильтрованным набором + разметка `.progress` в topbar),
  `styles.css` (`.progress`, `.progress__track`, `.progress__fill`, `.progress__label`).
- content: нет.
- tests: `frontend/smoke.mjs` — бар присутствует; подпись содержит `/`; после оценки ноды ширина
  `.progress__fill` > 0.

## Модель данных
Без изменений (UI-стейт, считается из `graph` + `scores` + активных фильтров).

## Решения (с обоснованием)
- **Область = отфильтрованный набор, не весь банк** — честно отражает «над чем сейчас работаем»; при
  отсутствии активных фильтров вырождается в прогресс по всему банку. Альтернатива (всегда весь банк)
  проще, но игнорирует фильтры и менее полезна по ходу интервью.
- **Предикат фильтра выносим в хелпер `passesFilters(n)`** и переиспользуем и в `coverage`, и (опционально)
  оставляем `dimmed` в `buildNodes` как есть — чтобы не дублировать логику молча. Минимально-инвазивный
  вариант: вычислить `coverage` инлайн тем же условием, что `dimmed` (block/diff/kind/tag). Берём инлайн —
  без рефактора `buildNodes`, риск рассинхрона мал (одно и то же условие, рядом). Зафиксировать комментарием.
- **Новый memo `coverage`**, имя не конфликтует с существующим per-block `progress`.
- **Никаких новых полей/эндпоинтов** — фронтовый расчёт, ноль механики.
