## Проблема / цель
Сейчас скачать можно только **результаты** интервью (оценённые вопросы + баллы, `downloadReport`). Нужен
экспорт **всего банка** вопросов с полными формулировками и ответами — чтобы распечатать/расшарить набор
вопросов, готовиться оффлайн, ревьюить покрытие. Без привязки к сессии и оценкам.

## Поведение / UX
- В шапке рядом с «📥 Скачать» — кнопка `🗂 Банк` (`.bankbtn`), всегда активна (оценки не нужны).
- Клик → скачивается самодостаточный HTML `interview_bank_<YYYY-MM-DD>.html`: все ноды, сгруппированы
  по блоку → суб-колонке → сложности (base→senior). Каждая запись: заголовок/вопрос (полностью), ответ
  (полностью), для задач — `starter_code` и `rubric`, плюс topic/теги/бейдж сложности. Баллов нет.
- Шапка документа: название, дата, счётчик «N вопросов», мини-сводка количества по блокам.
- Печать (`@media print`) — как в существующем отчёте (светлый, без теней).
- Крайний случай: пустой банк → секция «Банк пуст». Длинные ответы/код — `white-space: pre-wrap` (markdown
  НЕ рендерим — печатаем как текст; см. риски).

## Затрагиваемые слои и файлы
- backend: нет.
- frontend: `report.ts` (новые `buildBankHtml(nodes)` + `downloadBank(nodes)`, переиспользуя `esc`/`pad`),
  `App.tsx` (кнопка `🗂 Банк` в шапке → `downloadBank(graph)`).
- content: нет.
- tests: `frontend/smoke.mjs` — клик по `.bankbtn` отдаёт download с именем, содержащим `bank` и `.html`.

## Модель данных
Без изменений. Читаем существующий `QNode[]` (graph), все поля уже есть (question, answer, starter_code,
rubric, tags, topic, subblock, difficulty).

## Решения (с обоснованием)
- **Отдельная функция `buildBankHtml`, не параметр к `buildReportHtml`** — у банка другая структура (полные
  ответы, без оценок/сводки баллов); смешивать в один шаблон через флаги — менее читабельно. Переиспользуем
  только мелкие хелперы (`esc`, `pad`, группировку по DIFFS/BLOCK_ORDER/subOf).
- **Markdown не рендерим — текст как есть (`pre-wrap`, escaped)** — `report.ts` самодостаточный и не тянет
  md-парсер (в отличие от drawer в рантайме). Для печатного справочника читаемо; полноценный рендер md —
  на будущее. Зафиксировано в рисках.
- **Кнопка всегда активна** — банк не зависит от сессии/оценок (в отличие от `📥 Скачать`, который disabled
  при `scored===0`).
- **Светлый печатный стиль** — единообразно с отчётом результатов; банк предназначен для печати/шаринга.
