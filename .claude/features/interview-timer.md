## Проблема / цель
Ведущему интервью полезно видеть, сколько времени ушло на текущий вопрос и на всю сессию (тайм-менеджмент).
Сейчас таймеров нет.

## Поведение / UX
- В HUD рядом с заголовком — `⏱ M:SS · M:SS`: первое — время на текущем вопросе (сбрасывается при смене
  текущего), второе — время сессии (с начала интервью).
- Таймер сессии стартует при «Начать сессию» или при первом выборе вопроса; его начало хранится в
  localStorage (`timerStart`) — переживает перезагрузку; «Начать сессию» сбрасывает.
- Тикает раз в секунду (только когда есть текущий вопрос/идёт сессия).

## Затрагиваемые слои и файлы
- backend: нет.
- frontend: `App.tsx` (state `now`/`sessionStart`/`questionStart`, тик-эффект, сброс при currentId,
  helper `mmss`, отрисовка в HUD), `styles.css` (`.hud__timer`).
- content: нет. tests: smoke — таймер присутствует и инкрементируется.

## Модель данных
Без изменений (чистый UI-стейт; `timerStart` в localStorage).

## Решения (с обоснованием)
- **Тик через setInterval(1s) только при активном HUD/сессии** — не крутим таймер вхолостую.
- **`timerStart` в localStorage** — длительность интервью переживает reload (session-стейт не персистится,
  но wall-clock длительность осмысленна).
- Время на вопрос — без персиста (эфемерно, привязано к currentId).
