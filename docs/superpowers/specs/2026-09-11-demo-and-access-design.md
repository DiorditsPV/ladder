# Демо-режим и полный доступ — дизайн

Дата: 2026-09-11. Статус: утверждён владельцем в чате (вопросы по одному + итоговый дизайн).

## Цель
Сайт открывается как **демо**: без входа, на русском и английском, с двумя направлениями — «Дата-инженер» и
«Системный аналитик». **Полный режим** (все направления, включая новые технологии и профессии) — для владельца и
приглашённых, вход спрятан и не привлекает внимания.

## Решения владельца
1. Демо-посетитель пользуется чек-листом; отметки хранятся только в его браузере, на сервер ничего не пишется.
2. Приглашённые — «только разбор»: видят все направления и ведут свой чек-лист на сервере; карточки, направления,
   синхронизация и аккаунты — только у владельца.
3. Вход — незаметная ссылка «Вход» в нижнем углу стартового экрана плюс прямой адрес `#/login`.
4. Страница «Люди» для владельца есть: заведение аккаунта с одноразовым паролем, сброс, удаление; каждый меняет
   свой пароль сам; «Выйти» в настройках.
5. Английские версии демо-направлений — полный перевод текущих карточек, лёгким процессом (без повторной сверки фактов).

## Режимы и маршруты
Режим следует из сессии: нет сессии — демо, есть — полный.

| Адрес | Без входа (демо) | После входа (полный) |
|---|---|---|
| `#/` | стартовый экран | главная со всеми направлениями |
| `#/demo` | главная демо: только демо-направления текущего языка | → `#/` |
| `#/board/<pool>`, `#/bank/<pool>` | только демо-направления, иначе → `#/demo` | как сейчас |
| `#/login` | экран входа, после успеха → `#/` | → `#/` |
| `#/people` | → `#/` | страница «Люди» (только owner, иначе → `#/`) |
| прочее | → `#/` | → `#/` |

**Стартовый экран:** название «Ladder», одна фраза о продукте, большая кнопка «Открыть демо», переключатель RU/EN;
в нижнем правом углу — приглушённая ссылка «Вход» (мелкий текст цвета вторичного, без рамки и иконки).

**Демо-главная и доска:** карточки направлений с числом вопросов и полоской прогресса из браузера; «Открыть доску»
и «Банк вопросов». Скрыты: «+ Новое направление», меню ••• на карточке, «Обновить из файлов», правка/удаление/
скрытие карточек, добавление вопроса, импорт. Экспорт банка в HTML остаётся. Хоткеи 1/2/3, фильтры, поиск,
«только неразобранное» работают как в полном режиме.

**Язык контента:** у направления есть язык (`lang`, по умолчанию `ru`) и необязательная ссылка на оригинал
(`translation_of`). Главная при английском интерфейсе показывает перевод вместо оригинала там, где он есть;
остальные направления — на русском. Переключение языка на доске переводит на парное направление
(`#/board/data-engineer` ↔ `#/board/data-engineer-en`), если пара есть. Прогресс у оригинала и перевода раздельный.

## Бэкенд
**Флаги направления** — в `pool.yaml` и таблице `pools` (новые колонки с миграцией): `demo` (bool, по умолчанию
false), `lang` (`ru|en`, по умолчанию `ru`), `translation_of` (id направления или null). Sync переносит их из файлов;
направления, созданные в UI, — `demo=false`, `lang=ru`. `to_dict()` отдаёт их во фронт. Правки флагов из UI нет —
это свойство контента.

**Анонимное чтение** — новая зависимость `optional_user` (пользователь или None без 401):
- `GET /api/pools`: без сессии — только направления с `demo=true` тенанта `default`, поле `progress` отсутствует;
  с сессией — как сейчас.
- `GET /api/graph?pool=<id>`: без сессии — только если направление демо, иначе 401; без `pool` — 401.
- Всё остальное без сессии — 401, как сейчас. Анонимный доступ осознанно читает тенант `default`; это единственные
  две ручки, где `resolve_tenant` работает без `current_user` (комментарий у fail-open предупреждения в `tenancy.py`).

**Роли:** owner — всё; viewer (приглашённые) — чтение всех направлений и свой чек-лист. Ручки прогресса
(`GET/PUT/DELETE /api/progress`) — любой вошедший (сейчас PUT/DELETE требуют member). member остаётся как есть.

**Сессии:** несколько сессий на пользователя (повторный вход больше не выбивает прежний). Смена пароля
отзывает остальные сессии пользователя, текущая остаётся.

**Пароли и аккаунты:**
- `POST /api/auth/password` `{current_password, new_password}` — любой вошедший; неверный текущий → 403
  (не 401: фронт на 401 перезагружает страницу), новый короче 8 символов → 422.
- `POST /api/users` (owner) — `password` необязателен: без него сервер генерирует одноразовый пароль и отдаёт его
  в ответе один раз (`{..., "password": "…"}`); роль по умолчанию `viewer`.
- `POST /api/users/{id}/password` (owner) — новый одноразовый пароль в ответе один раз, сессии пользователя отозваны.
- `DELETE /api/users/{id}` (owner) — нельзя удалить себя; удаляются сессии и прогресс пользователя.

## Фронт
- `AuthGate` → контекст сессии `{user | null, refresh}`; без сессии рендерится роутер демо-режима, а не форма входа.
- Хранилище прогресса — одна абстракция: сервер для вошедших, `localStorage` (`ladder.progress.<pool>`) для демо;
  сводка на главной демо считается локально.
- Действия, запрещённые роли, не показываются (демо — все мутирующие; viewer — все, кроме чек-листа).
- Настройки (⚙ на доске и кнопка на главной полного режима): «Сменить пароль» (текущий, новый, повтор), «Выйти»;
  у owner — ссылка «Люди».
- Страница «Люди»: таблица (почта, роль, дата), «Добавить» (почта → одноразовый пароль с кнопкой «Скопировать»,
  показывается один раз), «Сбросить пароль», «Удалить» (подтверждение с почтой в тексте).
- Все новые строки — ключи в `i18n` + перевод в `en.ts`; `npm run i18n:check` зелёный.

## Контент
- `content/data-engineer/pool.yaml` и `content/system-analyst/pool.yaml` — только флаг `demo: true` (карточки не трогаем).
- Новые `content/data-engineer-en/` и `content/system-analyst-en/`: те же колонки, под-колонки и id уровней, подписи
  по-английски; `lang: en`, `translation_of: <оригинал>`, `demo: true`. Карточки — перевод всех текущих (61 и 44):

- Перевод — два субагента (по направлению), скрипт на python-frontmatter; гейт — импорт 0 ошибок в `/api/graph`.
- `demo/content-en` (скриншоты README) не трогаем; перевод `shots.mjs` на новые пулы — follow-up.

## Проверка
- pytest: анонимные правила (демо 200, не-демо 401, мутации 401), флаги из `pool.yaml`, viewer ставит прогресс и не
  правит карточки, несколько сессий, смена пароля (403/422/отзыв сессий), заведение/сброс/удаление аккаунтов.
- smoke: стартовый экран → «Открыть демо» → доска → отметка 1/2/3 → перезагрузка сохраняет отметку → переключение
  EN показывает перевод → `#/login` → полный режим → «Люди»: завести viewer → вход viewer → нет кнопок правки.
- `npm run build`, `npm run i18n:check`; скриншот стартового экрана и демо-доски перед PR.

## Вне скоупа
Самостоятельная регистрация, письма, ограничение частоты попыток входа (риск: вход на публичном сайте без
rate limit — отдельная задача), связь прогресса оригинала и перевода, перевод Kafka/Spark/X5.
