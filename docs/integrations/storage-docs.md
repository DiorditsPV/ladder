# Диски, СХД и документы

Куда складывать отчёты, записи интервью, вложения (резюме, тестовые задания). Двойная
ценность: **удобство** (файлы там, где их ищет команда) + **152-ФЗ** (хранение ПД в РФ).

## Системы рынка РФ

| Система | Тип | Интеграция |
|---|---|---|
| **Яндекс 360 для бизнеса** (Яндекс.Диск) | корпоративный диск/офис | REST API Диска, WebDAV, OAuth (Яндекс ID) |
| **VK WorkDisk / VK WorkSpace** | корпоративный диск/офис | API экосистемы VK |
| **Облако Mail (Mail.ru Cloud)** | диск | API/WebDAV |
| **МойОфис** (Squadus, Документы) | офис+хранилище, импортозамещение | API/WebDAV, on-prem |
| **Р7-Офис (R7-Office)** | офис+хранилище, импортозамещение | API, on-prem |
| **Yandex Object Storage / VK Cloud / Selectel** | объектное S3-хранилище | **S3-совместимый API** |
| **MinIO** (self-hosted) | объектное S3, on-prem | S3-совместимый API |

## Сценарии ценности
1. **Авто-выгрузка отчёта.** HTML/PDF-отчёт сессии (и бренд-версия) автоматически
   сохраняется в папку команды на корпоративном диске — по кандидату/дате.
2. **Хранение записей интервью** (если есть `video-vks-ru`) и вложений-резюме рядом.
3. **152-ФЗ.** ПД физически в российском облаке/on-prem, а не на зарубежном S3.

## Фича-кандидат
- **`storage-ru-disks` (P1).** Подключаемое внешнее хранилище для артефактов сессии:
  Яндекс 360 / VK WorkDisk / МойОфис / S3-совместимое (Yandex Object Storage, VK Cloud,
  Selectel, MinIO). Авто-сохранение отчётов и вложений по настраиваемой структуре папок.
  _Слои: backend — провайдер-хранилища за единым интерфейсом (S3 SDK + WebDAV + REST Диска),
  настройка подключения в воркспейсе; фронт — выбор «куда сохранять», статус выгрузки._

## Технические заметки
- **S3-совместимость — главный рычаг.** Один S3-клиент закрывает Yandex Object Storage,
  VK Cloud, Selectel, MinIO. Это самый дешёвый и переносимый вариант — делать его базовым,
  остальное (Диск/WebDAV) — поверх того же интерфейса хранилища.
- **WebDAV** покрывает Яндекс.Диск, Облако Mail, многие корпоративные диски — хороший
  «второй» протокол.
- **on-prem.** Для заказчиков без облака — MinIO/файловое хранилище как дефолт; то же
  абстрагирование провайдера.
- ⚠️ Эндпоинты, лимиты, нюансы авторизации Диск-API — сверить (см. `_verify.md`).
