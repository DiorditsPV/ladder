# Мессенджеры, уведомления и ВКС

Две темы: **уведомления/боты** (дёшево, очень заметно) и **видеоинтервью** (звонок прямо
из доски — сильный UX для удалённого найма).

## Мессенджеры и уведомления

| Система | Положение | Интеграция |
|---|---|---|
| **Telegram** | массовый, и личный, и рабочий | **Bot API** — самый простой и мощный канал |
| **VK Teams** (бывш. Myteam) | корпоративный мессенджер | Bot API |
| **Пачка (Pachca)** | корпоративный, SMB/средний | Webhooks/Bot API |
| **eXpress** | корп. мессенджер (безопасность/гос) | API/боты, on-prem |
| **Squadus** (МойОфис) | корп. мессенджер | API |

### Сценарии ценности
- **Приглашения и напоминания** интервьюеру/кандидату (за N минут до интервью).
- **Бот-ассистент:** «у вас интервью в 15:00», по итогу — «скоркарт готов, балл 4.2».
- **Эскалации:** напоминание «сессия не завершена/не выставлены оценки».

### Фича-кандидат
- **`notify-telegram-vkteams` (P1).** Уведомления и боты в Telegram / VK Teams / Пачка:
  напоминания о слотах, статусы по сессии, кнопки быстрых действий. Низкие усилия, высокая
  заметность.
  _Слои: backend — провайдер-нотификаций за единым интерфейсом (Telegram Bot API первым),
  шаблоны сообщений, привязка чата к пользователю; фронт — настройка каналов/событий._

## ВКС (видеоконференции) для удалённых интервью

| Система | Положение | Интеграция |
|---|---|---|
| **Яндекс Телемост** | Яндекс 360 | создание встреч (API/ссылки), OAuth Яндекс ID |
| **TrueConf** | enterprise/on-prem, гос | API, серверная установка |
| **Контур.Толк** | растущий B2B | API создания встреч |
| **VK Звонки** | экосистема VK | API/ссылки |
| **МТС Линк** (бывш. Webinar) | вебинары/встречи | REST API |

### Сценарии ценности
- **Звонок из доски.** Кнопка «начать видеоинтервью» создаёт встречу и кладёт ссылку в
  сессию; кандидату уходит приглашение (через `notify-*`).
- **Тайминг + запись.** Длительность звонка → в сессию; запись (если есть) → в
  `storage-ru-disks`.

### Фича-кандидат
- **`video-vks-ru` (P2).** Создание видеовстреч из сессии: Яндекс Телемост / TrueConf /
  Контур.Толк / VK Звонки. Ссылка в карточке сессии, приглашение участникам.
  _Слои: backend — провайдер ВКС за единым интерфейсом (создание встречи, ссылка),
  привязка к сессии; фронт — «начать видеоинтервью», блок ссылки/статуса._

## Технические заметки
- **Telegram Bot API — первый шаг** для уведомлений: не требует одобрения, мгновенный
  эффект демо. VK Teams/Пачка — поверх того же интерфейса нотификаций.
- **ВКС:** часть систем даёт только «создать встречу + ссылку», часть — полноценные
  комнаты/записи. Для on-prem-заказчиков целиться в TrueConf.
- ⚠️ Возможности API (особенно запись/планирование) сильно разнятся — сверить (см. `_verify.md`).
