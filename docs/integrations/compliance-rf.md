# Соответствие требованиям РФ (compliance)

Не «фича-коннектор», а сквозные требования к продукту и развёртыванию. Для госсектора и
крупного бизнеса — **блокирующие**: без них сделка не состоится, какими бы хорошими ни были
интеграции.

## Ключевые требования

| Требование | Суть | Влияние на продукт |
|---|---|---|
| **152-ФЗ (персональные данные)** | ПД граждан РФ обрабатывать/хранить в БД на территории РФ; согласие субъекта; защита данных | хранилище и БД — в РФ-облаке/on-prem; экран согласия на обработку ПД; политика хранения/удаления |
| **Реестр российского ПО (Минцифры)** | госкомпании обязаны закупать ПО из реестра | подать продукт в реестр; следствие — стек/зависимости без «недружественных» рисков |
| **Локализация инфраструктуры** | не зарубежные облака/CDN | развёртывание в Yandex Cloud / VK Cloud / SberCloud / on-prem |
| **ГОСТ-шифрование / КриптоПро** | для части гос/банков | поддержка ГОСТ TLS/ЭЦП по требованию (опционально) |
| **Аудит и журналирование** | ИБ-службы требуют логи доступа/действий | журнал интеграций и доступа (есть в `integration-hub`) |
| **Импортозамещённое окружение** | Astra Linux, PostgreSQL, российские СУБД | подтверждённая работа на Astra Linux + PostgreSQL |

## Влияние на архитектуру
- **On-prem как первоклассный режим развёртывания**, не «костыль»: всё (БД, хранилище,
  SSO, ВКС) должно иметь self-hosted-вариант (PostgreSQL, MinIO, Keycloak, TrueConf).
- **Никаких жёстких завязок на зарубежные облака** в коде интеграций — провайдеры за
  абстракциями (см. интерфейсы в `storage-docs.md`, `sso-identity.md`).
- **Данные кандидата** = персональные данные. Экран согласия, срок хранения, удаление по
  запросу — заложить в модель сессии/кандидата.

## Фича-кандидат
- **`compliance-rf` (P1 для гос/крупных).** Пакет соответствия: экран согласия на обработку
  ПД, политика хранения/удаления, режим on-prem (PostgreSQL + MinIO + Keycloak), подготовка
  к подаче в реестр российского ПО, журналирование доступа.
  _Скорее инфраструктурно-юридический трек, чем коннектор; усилия L, но открывает B2G и
  крупный бизнес._
