# Календарь, почта и страница расписания

Закрывает «рабочий день интервьюера»: встречи и переписка с кандидатом не в отдельной
вкладке, а внутри сервиса, с переходом из встречи **прямо в доску интервью** одним кликом.
Сильный UX-аргумент и для одиночного интервьюера, и для команды.

## Системы рынка РФ

| Система | Тип | Протокол/интеграция |
|---|---|---|
| **Яндекс 360 (Почта + Календарь)** | почта/календарь | CalDAV, IMAP/SMTP, REST API, OAuth (Яндекс ID) |
| **VK WorkMail / VK Календарь** | почта/календарь | API экосистемы VK, CalDAV/IMAP |
| **Mail.ru для бизнеса** | почта | IMAP/SMTP, API |
| **МойОфис Mailion / Календарь** | почта/календарь (импортозамещение, on-prem) | IMAP/SMTP, CalDAV, API |
| **RuPost, Tegu, CommuniGate Pro** | почтовые серверы (замена Exchange) | IMAP/SMTP, CalDAV |
| **iCalendar (ICS) / CalDAV** | универсальные протоколы | базовый знаменатель для любого календаря |
| **SMTP/IMAP** | универсальные протоколы | базовый знаменатель для любой почты |

## Сценарии ценности

1. **Встреча → кандидат на странице расписания.** Поставили встречу в календаре (или
   создали слот в сервисе) — кандидат появляется на отдельной странице «Расписание/
   Сегодня» с датой, временем, позицией.
2. **Один клик из встречи в доску.** Из карточки встречи — переход прямо в блок
   интервьюирования: открывается доска с подобранным треком/набором вопросов и привязанной
   сессией кандидата. Не нужно искать/создавать сессию вручную.
3. **Приглашения по почте.** Отправка приглашения кандидату и интервьюеру (с ICS-вложением,
   ссылкой на ВКС из `video-vks-ru`), напоминания (через `notify-telegram-vkteams`).
4. **Двусторонний синк.** Перенос/отмена встречи в корпоративном календаре отражается в
   сервисе и наоборот; занятость интервьюеров видна при назначении.
5. **(Опц.) разбор ответов.** Подтверждение/отказ кандидата по почте (RSVP) обновляет
   статус слота.

## Фичи-кандидаты

- **`scheduler-page` (P1).** Отдельная страница-расписание («Сегодня» / неделя): кандидаты
  появляются при назначении встречи; карточка слота показывает кандидата, время, позицию,
  трек; **кнопка «Начать интервью» ведёт прямо в доску** с уже привязанной сессией. Это
  UX-ядро запроса.
  _Слои: модель Meeting/Slot (кандидат, время, интервьюер, трек, ссылка на session);
  backend CRUD слотов; фронт — новая страница-календарь (день/неделя) + роутинг
  слот→доска(session); глубокая ссылка вида `/board?session=…`._

- **`calendar-email-sync` (P1).** Синхронизация с корпоративным календарём и почтой:
  CalDAV (Яндекс/VK/МойОфис) + ICS, IMAP/SMTP для приглашений и напоминаний; двусторонний
  синк встреч, отправка ICS-инвайтов, занятость интервьюеров.
  _Слои: backend — провайдер календаря за единым интерфейсом (CalDAV/ICS база + REST
  Яндекс/VK поверх), почтовый провайдер (SMTP/IMAP), маппинг встреча↔слот; опирается на
  integration-hub (токены/вебхуки) и связан со scheduler-page._

> Делить на две фичи осознанно: `scheduler-page` даёт ценность даже **без** внешнего
> календаря (внутренние слоты + ручное назначение), а `calendar-email-sync` навешивает
> синхронизацию с корпоративным стеком сверху. Можно поставлять волнами.

## Технические заметки

- **CalDAV/ICS — базовый протокол.** Один CalDAV-клиент покрывает Яндекс Календарь, VK,
  МойОфис и большинство замен Exchange; REST конкретных вендоров — поверх, для удобств.
- **SMTP/IMAP — базовая почта;** для on-prem/закрытого контура это вообще единственный
  доступный путь (внешние API недоступны).
- **Глубокая ссылка слот→доска** — ключевая деталь UX: слот хранит `session_id` (или
  создаёт сессию по треку при первом входе), переход открывает доску в контексте кандидата.
- **Часовые пояса** — хранить в UTC, отображать в TZ пользователя/воркспейса.
- ⚠️ Эндпоинты/скоупы Яндекс/VK Календаря и нюансы CalDAV-серверов — сверить (см. `_verify.md`).
