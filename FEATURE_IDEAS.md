> **Сложность (1–5)** учитывает и инженерную работу, и **барьер доступа** к внешней системе — он часто тяжелее кода: платный тариф API, корпоративный аккаунт, OAuth-приложение или партнёрские/личные контакты с вендором либо заказчиком. Внутри блока — от простой к сложной. `P0–P2` — приоритет ценности (отдельно от сложности).
> 🟢 1–2 низкая · 🟡 3 средняя · 🟠 4 высокая · 🔴 5 очень высокая.

## Продающие фичи (платная версия)
**free** = один интервьюер локально; **paid** = команда / облако / интеграции. Внешний доступ не нужен.

- [ ] white-label-reports — 🟢 2 — отчёты под брендом: лого, batch-экспорт, шаринг по ссылке. Внутренняя работа.
- [ ] team-workspace — 🟠 4 — командное облако: история кандидатов, общий банк, роли. Мульти-тенант + миграция на Postgres + RBAC; база остального тира.
- [ ] live-panel — 🟠 4 — панельные интервью в реальном времени: синхрон оценок/заметок, сведение баллов. Websockets + разрешение конфликтов.

## Интеграции с внешними системами (РФ)
Встраивание в инфраструктуру российских компаний — одна из важнейших тем для продаж в РФ. Главный множитель сложности — **доступ**: корпоративный аккаунт, платный API, OAuth-приложение или партнёрские/личные контакты с вендором/заказчиком.
Детали и карта рынка: [`docs/integrations/`](docs/integrations/README.md) · сверка перед реализацией — [`_verify.md`](docs/integrations/_verify.md).

- [ ] notify-telegram-vkteams — 🟢 2 · P1 — уведомления/боты: Telegram (бесплатный открытый Bot API), VK Teams, Пачка. Минимальный барьер доступа.
- [ ] scheduler-page — 🟢 2 · P1 — страница-расписание: кандидат при встрече → клик прямо в доску. Внутренняя, работает и без внешнего календаря.
- [ ] integration-hub — 🟡 3 · P0 — коннектор-платформа: токены, маппинг, вебхуки с очередью, журнал. Объёмный, но внутренний фундамент.
- [ ] storage-ru-disks — 🟡 3 · P1 — хранилище артефактов: S3-совместимое (MinIO бесплатно self-host) + Яндекс 360 / VK / МойОфис. Удобство + 152-ФЗ.
- [ ] calendar-email-sync — 🟡 3 · P1 — синк с календарём/почтой: открытые стандарты CalDAV/ICS/SMTP/IMAP; REST Яндекс/VK — через OAuth-приложение.
- [ ] sso-ru-identity — 🟠 4 · P1 — корпоративный вход: OIDC/SAML/LDAP (Keycloak/AD/ALD Pro бесплатны), Yandex ID / VK ID — нужен зарегистрированный OAuth-апп.
- [ ] crm-bitrix-amocrm — 🟠 4 · P2 — экспорт в Bitrix24 (вебхуки просты) / amoCRM (платный). Нужен аккаунт заказчика.
- [ ] hh-jobboards-import — 🟠 4 · P1 — импорт вакансий/откликов из hh.ru. Нужен аккаунт работодателя + одобрение API; доступ к резюме ограничен (ПД/платно).
- [ ] video-vks-ru — 🟠 4 · P2 — видеоинтервью из доски: Телемост / TrueConf / Контур.Толк / VK Звонки. API разнятся, часть — платные бизнес-планы.
- [ ] ats-huntflow-sync — 🔴 5 · P0 — двусторонний синк с Huntflow. Платный продукт: нужен инстанс/токены заказчика и партнёрский доступ — барьер высокий при умеренном коде.
- [ ] erp-1c-hrm — 🔴 5 · P2 — обмен с 1С:ЗУП/1С:ERP. Единого API нет: доработка на стороне 1С под конфигурацию, интегратор и контракты.
- [ ] compliance-rf — 🔴 5 · P1(гос) — 152-ФЗ, on-prem, реестр российского ПО, журналирование. Юридика + сертификация, длинный бюрократический трек.
