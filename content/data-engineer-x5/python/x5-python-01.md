## Задача
Текст разбит на абзацы строками-разделителями, которые состоят **только** из символов `@` (одного или нескольких). Напиши функцию `get_paragraph(n, path)`, которая возвращает n-й абзац файла. Пример входа и подсказка по API файла — в стартовом коде. По готовому решению пройди вслух по примеру из условия.

## Эталон
Опорное решение — один проход по файлу построчно. Разделитель распознаётся отдельной функцией: строка после `rstrip("\n")` непустая и целиком состоит из `@`. Строки, которые не являются разделителем, копятся в текущий абзац; на разделителе абзац закрывается, если он непустой.

```python
def is_delimiter(s):
    s = s.rstrip("\n")
    return bool(s) and all(ch == "@" for ch in s)

def get_paragraph(n, path):
    paragraphs, current = [], []
    with open(path) as f:
        for line in f:
            if is_delimiter(line):
                if current:
                    paragraphs.append("".join(current))
                    current = []
            else:
                current.append(line)
        if current:
            paragraphs.append("".join(current))
    return paragraphs[n]
```

Критерий приёмки — структура решения, а не запуск: детали реализации можно опустить, но каждый найденный корнер-кейс нужно произнести вслух. Самый дешёвый способ проверить себя — прогнать решение по примеру из условия.

Что обычно ломается. Первое — `@` внутри контента: строка `esrtvser.com` (или `esrt@vser.com`) — это текст, а не разделитель; проверка `"@" in line` даёт ложные срабатывания, нужна проверка «все символы — `@`». Второе — подряд идущие разделители (`@@@@@`, затем `@@`) не должны рождать пустые абзацы, отсюда проверка `if current`. Третье — последний абзац: если сброс происходит только на разделителе, а после последнего абзаца разделителя нет, он теряется и функция возвращает `None`. Четвёртое — `n` за границами: нужно осознанно выбрать поведение (исключение `IndexError` или `None`) и договориться, с нуля или с единицы нумеруем. Пятое — `len(line)` считает и `\n`, если длина строки где-то используется.

Эффективность — следующий уровень: держать весь список абзацев в памяти не обязательно. Можно считать номер текущего абзаца по ходу чтения и вернуть его, как только счётчик дошёл до `n`, — тогда память O(размер одного абзаца), а файл читается ровно до нужного места. Построчная итерация `for line in f` уже даёт потоковое чтение без `f.read()` целиком.
