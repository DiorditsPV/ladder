## Вопрос
Что такое Catalyst и через какие этапы проходит запрос, прежде чем превратиться в таски?

## Ответ
Catalyst — оптимизатор Spark SQL. Любой запрос, написанный на SQL или через DataFrame API, он превращает в дерево операций и шаг за шагом переписывает, пока не получится план, который можно исполнить тасками.

Этапы:
- **analyzed** — имена таблиц и колонок сверены с каталогом, типы выведены; опечатка в имени колонки падает здесь;
- **optimized** — правила переписывают дерево: фильтры опускаются к чтению данных, ненужные колонки выбрасываются, константы вычисляются заранее;
- **physical** — для каждой операции выбрана реализация: какую стратегию джойна взять и где нужен shuffle (узел `Exchange`).

Физический план затем режется на стейджи и таски.

DataFrame API и `spark.sql` строят одно и то же дерево и дальше идут одним путём, поэтому по скорости не отличаются — выбирай то, что проще читать.

Посмотреть все этапы:
```python
df = (spark.table("lake.sales.orders")
      .where("order_date = '2026-09-01'")
      .groupBy("store_id").count())
df.explain(mode="extended")
```
